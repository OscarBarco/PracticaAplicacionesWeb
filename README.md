# Introduccion_IDE - Configuración del Entorno

## Descripción del Proyecto

Este proyecto forma parte del Taller 1 del curso Técnico en Programación – Diseño de APP en COMPUESTUDIO. Su propósito principal es configurar, organizar y validar un entorno de desarrollo local funcional. Sirve como base estructurada para futuros proyectos de programación, garantizando la correcta integración del editor de código con las herramientas y lenguajes requeridos.

## Herramientas Instaladas

A continuación, se listan las herramientas configuradas en el entorno junto con sus versiones verificadas:

- **Visual Studio Code:** Entorno de Desarrollo Integrado (IDE) principal.
- **Python:** Versión 3.14.7
- **Git:** Versión 2.55.0.windows.5

## Extensiones Instaladas en el IDE

Para agilizar el flujo de trabajo, se instalaron las siguientes extensiones en el Marketplace de VS Code:

- **HTML CSS Support:** Proporciona autocompletado inteligente para clases e IDs de CSS dentro de los archivos HTML.
- **Live Server (Ritwick Dey):** Levanta un servidor local que recarga automáticamente el navegador al guardar cambios en el código.
- **Material Icon Theme (Philipp Kief):** Asigna íconos visuales distintivos a los archivos y carpetas, facilitando la navegación en el proyecto.
- **Prettier - Code formatter:** Herramienta para formatear y mantener un estilo limpio y estandarizado en el código HTML, CSS y JavaScript.
- **Python, Pylance y Python Debugger (Microsoft):** Conjunto de herramientas que brindan soporte completo para la ejecución, autocompletado avanzado y depuración de código Python.

## Estructura de Carpetas del Proyecto

El proyecto está organizado de la siguiente manera:

- **`CSS/`**: Carpeta que contiene `styles.css`, el archivo responsable del diseño visual y la presentación de la página.
- **`imagen/`**: Directorio destinado a los recursos multimedia, como la imagen de prueba `Gato.jpg`.
- **`js/`**: Contiene `Scripts.js`, el archivo dedicado a la lógica de programación y el dinamismo del sitio mediante JavaScript.
- **`index.html`**: El documento raíz de la estructura web, donde se integran y enlazan los estilos, la imagen y los scripts.
- **`README.md`**: El presente archivo de documentación del entorno.
